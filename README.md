# Assay

Assay is a monthly review of AI for science. Each edition picks about fifteen pieces of open work, such as papers, company reports, datasets, software and essays, and publishes a short assessment of each one.

Read it at https://assay.pub

This is a pilot. The assessments are drafted by AI models working from the original sources, and no editor has reviewed them yet. The [charter](content/pages/charter.md) explains what Assay is for. The [method](content/pages/method.md) explains how work is found, chosen and rated.

## In this repository

- `content/` holds the editions and assessments as text files.
- `site/` holds the program and templates that turn them into the website.
- `monitor/`, `editorial/` and `scripts/` hold the tools for drafting an edition. The steps are in [editorial/PROTOCOL.md](editorial/PROTOCOL.md).

The website is rebuilt from the `main` branch whenever it changes.
